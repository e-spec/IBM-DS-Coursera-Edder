## 🚀 Key Project: Applied Data Science Capstone
> **Predicting SpaceX Falcon 9 First Stage Landings**
>
> The final project involves predicting if the first stage of a Falcon 9 rocket will land successfully. This includes data collection via SpaceX API, web scraping, and building predictive models.

* **Objective:** Build a machine learning model to predict landing success to help a competitor estimate launch costs.
* **Methods:** Data Wrangling, SQL Analysis, Interactive Map Creation (Folium), ML Model Comparison.
