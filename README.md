# IBM Data Science Professional Certificate - Coursera

This repository documents my progress through the **IBM Data Science Professional Certificate**. It brings together notebooks, lab work, projects, presentation materials, and supporting resources developed throughout the program.

## 📊 Program Overview
| Course | Title | Status | Key Skills |
| :--- | :--- | :---: | :--- |
| **C1** | What is Data Science? | ✅ | Foundations, Data Literacy |
| **C2** | Tools for Data Science | ✅ | Jupyter, RStudio, GitHub |
| **C3** | Data Science Methodology | ✅ | Problem Definition, Analytical Approach, Requirements |
| **C4** | Python for Data Science & AI | ✅ | Python Fundamentals, APIs, Web Scraping |
| **C5** | Python Project for Data Science | ✅ | Dashboards, Data Extraction, yfinance |
| **C6** | Databases and SQL with Python | ✅ | SQL, Relational Databases, Python DB-API |
| **C7** | Data Analysis with Python | ✅ | Pandas, NumPy, SciPy, Data Wrangling, EDA |
| **C8** | Data Visualization with Python | ✅ | Matplotlib, Seaborn, Folium, Dash |
| **C9** | Machine Learning with Python | ✅ | Regression, Classification, Clustering |
| **C10** | Applied Data Science Capstone | ✅ | SpaceX Project, Folium, Plotly, Predictive Analysis |
| **C11** | Generative AI for Data Science | ✅ | Generative AI in Data Science, Model Building, Final Project |
